# KuaiSAR多任务推荐系统

基于快手KuaiSAR数据集(2.5万用户、200万视频、700万条交互,9天时间跨度)构建的
click/like/follow点击行为预测与完播率(观看时长/视频时长)回归的四任务联合推荐模型。

## 核心工作

- 设计并实现PLE多任务架构,CGC渐进式特征分离:融合原始特征(用户/物品/作者ID、
  时长、类目等11维)与自定义特征工程(用户分类目popular率、用户对特定作者点赞
  次数、物料/作者历史点赞率等19维),共30维输出至各任务
- 采用不确定性加权自动平衡多任务损失(分任务BCE + 回归任务MSE)联合早停策略
  (≥3项指标连续未提升后停止),缓解任务竞争问题。网络接口条模块各含专有共享
  参数量。对门控塌塄的问题,加入负载损失和带噪门控
- 最终指标(AUC/GAUC/MAE/RMSE)联合早停策略

## 结果

| 指标 | 数值 (AUC / GAUC) |
|---|---|
| click | 0.7516 / 0.6935 |
| like | 0.8484 / 0.8065 |
| follow | 0.8012 / 0.7764 |

watch_ratio MAE = 0.4058, RMSE = 0.6116。精度与逐任务单独训练的XGBoost baseline基本持平。
